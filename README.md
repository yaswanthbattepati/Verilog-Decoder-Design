# Verilog HDL Decoder Design and Simulation

## Overview
This project implements 2-to-4 and 3-to-8 decoders using Verilog HDL. It demonstrates combinational logic design, RTL simulation, and waveform-based functional checking.

## Problem Statement
Design decoder circuits that map binary input combinations to the corresponding output lines.

## Implementation
- Designed 2-to-4 and 3-to-8 decoder modules using Verilog HDL.
- Applied input combinations to check decoder output behavior.
- Inspected simulation waveforms to compare outputs with expected logic behavior.

## Tools Used
- Verilog HDL
- Cadence Xcelium (NC-Sim)
- SimVision

## Project Structure
- `rtl/` — Verilog design files
- `testbench/` — Testbench files, if included
- `simulation/` — Relevant simulation screenshots, if included
